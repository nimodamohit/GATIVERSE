# GATIVERSE - Shared Module

This directory is reserved for shared TypeScript interfaces, constants, and utilities used across microservices (e.g. backend and frontend).

## Purpose
Provides a single source of truth for cross-cutting data contracts, shared types, and domain constants.

## Planned Scope (Future Phases)
- Shared Data Contracts (Train, Station, Route interfaces)
- WebSocket payload DTO definitions
- System-wide constants and enum declarations
